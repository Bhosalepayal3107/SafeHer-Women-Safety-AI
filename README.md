# SafeHer – AI-Powered Women's Safety Platform

**SafeHer** is a women’s safety project designed to help users access safety-related features and resources through a simple, user-friendly web interface.

## 🌟 Project Overview

Women's safety involves both physical and digital environments. SafeHer aims to bring useful safety features together in one platform, helping users find relevant information and access available safety tools.

## 🎯 Objectives

- Provide an accessible, easy-to-use safety-focused web application.
- Organize women's safety features in one interface.
- Help users navigate safety resources and available tools.
- Explore how AI and web technologies can support women's safety.

## ✨ Features

- **Safety Dashboard:** A central interface to access the application's features.
- **Feature Navigation:** Navigate between available sections using the sidebar or navigation links.
- **Responsive Interface:** A web interface designed for convenient use.
- **Safety Resources:** Access safety-related information and resources implemented in the project.

*Note: The features available depend on the current implementation. Do not describe a feature as operational unless it has been implemented and tested.*

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Bhosalepayal3107/SafeHer-Women-Safety-AI.git
cd SafeHer-Women-Safety-AI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can run the app using the virtual environment's Python executable directly.

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Open your browser and visit:

http://127.0.0.1:5000/
